# 七星数智公开一体化云平台

> 七星农场政务公开网站静态原型。

这是一个面向七星农场管理区、直属单位、机关部门的政务公开展示原型，核心目标是把原来分散在纸质材料、微信群、表格里的公开事项，整理成一个群众能看、管理员能管、领导能总览的数据化平台。

## 项目功能

- 首页六大栏目入口：党务公开、政务公开、财务公开、职工疑问、干部答疑、通知公告
- 普通用户注册浏览：登记姓名和电话后查看公开信息
- 管理员登录演示：普通管理员和最高权限管理员两种角色
- 信息筛选与公开列表：按栏目、单位、状态、公开周期查看记录
- 数据驾驶舱：展示公开事项总览、单位覆盖、栏目分布等数据
- 前端模拟数据：当前版本使用 `script.js` 内置示例数据，便于演示

## 文件结构

```text
.
├── index.html        # 页面结构
├── styles.css        # 页面样式
├── script.js         # 交互逻辑与模拟数据
└── assets/           # 首页背景、图标、入口图等视觉资源
```

## 本地预览

直接双击 `index.html` 即可打开。

如果浏览器安全策略影响图片或交互，可以在项目目录启动一个本地静态服务：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```
